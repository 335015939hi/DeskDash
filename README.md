# Desktop Dashboard

A **KDE Plasma 6 desktop containment** that shows an empty desktop until you activate "Peek at Desktop" — then it reveals widgets. Based on Plasma's default desktop containment, it should inherit your existing widgets and settings.

## ✨ Features

- **Clean Desktop by Default** — Shows an empty, distraction-free desktop until you need it
- **Peek at Desktop** — Reveals folder contents and widgets when you trigger "Peek at Desktop" (default: <kbd>Meta</kbd>+<kbd>,</kbd> or mouse gesture)

## 📦 Installation

# cd to your Plasmoid folder
cd ~/.local/share/plasma/plasmoids/

# Clone the repository
git clone https://github.com/335015939hi/DeskDash.git com.tony.deskdash

# Activate DeskDash
Right-click on desktop
Desktop and Wallpaper
Layout -> choose DeskDash
